# PR 03 MyBatis 문서의 읽기 화면과 기기 검증

[PR 02 정적 HTML 빌드](./mybatis-web-pr-02-build.md)의 산출물에 반응형 읽기 화면을 적용하고, 최종 파일을 실제 열기 경로에서 검증한다.

## 달성 목표

독자가 모바일과 데스크톱에서 본문과 코드를 편하게 읽고 원하는 절로 이동할 수 있게 한다. 한국어는 단어를 중간에서 쪼개지 않고, 폭을 넘는 코드와 표는 각 영역에서 내용을 끝까지 볼 수 있게 한다.

## 태스크

각 태스크의 완료 조건을 확인한 항목부터 `[x]`로 바꾸고, 필요한 검증 근거를 PR에 남긴다. 모든 태스크 완료 조건을 체크한 뒤 최종 완료 조건을 별도로 점검하고 체크한다.

### MYB-03-01 화면 폭에 맞는 본문과 목차 구성

- [ ] Tailwind로 모바일에서는 본문 위에 목차를 둔 단일 열, 데스크톱에서는 본문과 목차를 나란히 볼 수 있는 레이아웃을 구성했다. 넓은 화면에서도 본문 최대 너비와 행간을 조절해 문단을 따라 읽기 쉽다.
- [ ] 제목, 본문, 표의 설명에 `lang="ko"` 문서의 `word-break: keep-all`을 적용해 한국어 어절 사이에서 줄이 바뀐다. 긴 URL은 짧은 링크 문구로 표시하고, 한 줄에 담기 어려운 코드 식별자는 코드 블록에서 읽을 수 있게 편집했다. [Tailwind CSS 줄바꿈 유틸리티](https://tailwindcss.com/docs/word-break)
- [ ] 목차 링크에 키보드로 접근할 수 있고 포커스가 눈에 보인다. 링크를 따라갔을 때 대상 제목이 가려지지 않으며, 브라우저의 뒤로 가기로 이전 위치로 돌아갈 수 있다.

### MYB-03-02 코드와 표 가독성 조정

- [ ] Java, XML, SQL 블록에 예제 종류나 파일명이 표시된다. 배경과 토큰 색이 구분되고 들여쓰기와 원래 줄이 유지되며, 선택하고 복사한 코드에 라벨이 섞이지 않는다.
- [ ] 폭이 넓은 코드와 표는 각 영역 안에서 가로로 움직일 수 있고, 페이지 전체에는 가로 스크롤이 생기지 않는다. 해당 영역은 터치와 키보드에서 끝까지 볼 수 있다.
- [ ] 채택한 다이어그램은 좁은 화면에서도 글자와 연결선을 읽을 수 있고, 그림 아래 설명으로 핵심 관계를 확인할 수 있다.

### MYB-03-03 프로덕션 HTML과 열기 경로 검증

- [ ] 프로덕션 빌드에서 320px, 390px, 768px, 1280px 너비를 확인했다. 화면별로 목차 이동, 한글 어절 줄바꿈, 긴 코드와 표 스크롤을 점검했다.
- [ ] Android와 iOS 실제 기기에 `index.html`만 복사하고 비행기 모드에서 파일을 직접 열었다. 각 기기의 파일 앱 또는 로컬 HTML을 표시할 수 있는 뷰어에서 본문·스타일·코드 강조가 보이고 목차가 이동한다. 검증에 사용한 OS, 앱과 열기 경로를 PR에 기록했다.
- [ ] 데스크톱 브라우저에서도 오프라인으로 파일을 열어 같은 내용을 확인했다. 데스크톱과 모바일의 대표 화면을 PR에 남겼다.
- [ ] README에 `bun run build` 사용법, 배포할 파일 경로, 실제로 확인한 모바일 열기 방법을 추가했다.

## 최종 완료 조건

- [ ] `bun run lint`, `bun run format:check`, `bun run build`가 모두 성공하고, 최종 산출물은 `dist/index.html` 한 파일로 전달할 수 있다.
- [ ] Android, iOS, 데스크톱의 확인된 열기 경로에서 인터넷과 서버 없이 본문 읽기, 목차 이동, 코드 읽기가 가능하다.
- [ ] 320px 모바일 화면부터 1280px 데스크톱 화면까지 페이지 전체의 가로 스크롤 없이 읽을 수 있다. 본문의 한국어 어절은 유지되고, 긴 코드와 표는 해당 영역에서 끝까지 볼 수 있다.
